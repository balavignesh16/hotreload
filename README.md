# HotReload

A lightweight and efficient live-reloading utility written in Go. `hotreload` automatically monitors your file system for changes and instantly restarts your server or application, drastically speeding up development workflows.

## Features
- **Fast & Compiled**: Written in Go for maximum performance.
- **Cross-Platform**: Works natively on Windows, Linux, and macOS.
- **Simple Configuration**: Easy to set up and integrate into any project.

## Tech Stack
- Go (Golang)

## Getting Started
1. Clone the repository.
2. Use `make` to build the executable from the `Makefile`.
3. Run `./hotreload.exe` (or the respective binary for your OS) in your project directory.
